# NOVA – Interior & Furniture Landing Page

NOVA is a modern and responsive landing page for an interior design and furniture brand.

##  Features

- Responsive design for desktop, tablet, and mobile
- Modern interior design layout
- Hero section
- About NOVA section
- Services section
- Furniture showcase
- Projects section
- Contact section
- Footer
- Smooth hover effects and animations

##  Technologies

- React.js
- Tailwind CSS
- Vite
- JavaScript
- HTML5
- CSS3
